Privacy Policy

Last updated: May 2026

Drop-Tumblr is a personal productivity tool used for managing automated uploads to Tumblr via the Tumblr API.

Data Collection

This application does not collect or store any personal data on external servers. All image data and API credentials provided by the user are stored locally on the user's hosting environment (e.g., PythonAnywhere).

API Usage

The application only accesses the specific Tumblr blogs as authorized by the user through their provided API tokens for the sole purpose of automated image posting and queue management.

Third-Party Services

This application interacts with the Tumblr API. For information on how Tumblr handles your data, please refer to the Tumblr Privacy Policy.

Contact

If you have any questions about this privacy policy, you may contact the administrator of your instance.
