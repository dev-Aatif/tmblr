Privacy Policy for Drop-Pin

Last updated: May 02, 2026

Drop-Pin is a personal productivity tool used for managing automated uploads to Pinterest via the Pinterest API.

Data Collection

This application is for personal use only. It does not collect, store, or transmit any personal user data to third parties. All authentication tokens are stored locally within the user's private environment.

Data Usage

The application only accesses the specific Pinterest boards and pins as authorized by the user through their provided API token for the sole purpose of automated image posting.

Security

The application is hosted on a secure environment and uses standard API security practices.

Contact

For any inquiries regarding this policy, please contact the application owner through the provided contact details.
